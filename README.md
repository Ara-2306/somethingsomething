# Little Arcade Messenger

## Publish with GitHub Pages

1. Create a GitHub repository and extract these files into its top level.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the default branch and **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing, then open the Pages link.

The same files work for a project site under a repository path. The app derives that path automatically.

The chat messages are encrypted in the shipped JavaScript data and decrypt only after both password screens. Anyone with a copy can try password guesses offline; choose longer secrets if you replace the current ones.
